Cloud accounts to create now (free, ~10 min)

  • IBM Quantum Platform — quantum.cloud.ibm.com (Open Plan: ~10 min/month of real QPU time). Create an API key + instance CRN.
  • AWS Braket (later, optional) — aws.amazon.com/braket (pay-per-shot).
  • Azure Quantum (optional) — azure.microsoft.com/products/quantum.

Never commit API keys. Use QiskitRuntimeService.save_account(...) (stored in ~/.qiskit) or environment variables.
